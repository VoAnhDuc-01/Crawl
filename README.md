

Script hỗ trợ tự động hóa quá trình nhập danh sách số CCCD/Mã định danh cá nhân của học sinh trường THPT Chuyên Phan Ngọc Hiển (Cà Mau) vào cổng tra cứu tuyển sinh chính thức của Trường Đại học Sư phạm TP.HCM, sau đó tổng hợp kết quả ra file dữ liệu.

- **Web:** [xettuyen.hcmue.edu.vn/tra-cuu-ket-qua](https://xettuyen.hcmue.edu.vn/tra-cuu-ket-qua)
- **Data:** Học sinh THPT Chuyên Phan Ngọc Hiển (Cà Mau)
- **Tự động điền dữ liệu:** Tự động điền danh sách số CCCD vào hệ thống tra cứu.
- **Xử lý bất đồng bộ (Async/Await):** Giữ khoảng thời gian chờ hợp lý để không làm quá tải máy chủ.
- **Xuất kết quả:** Tự động gom kết quả và tải file `.json` về máy tính sau khi chạy xong.


## Hướng dẫn sử dụng 🤯

1. WEB [https://xettuyen.hcmue.edu.vn/tra-cuu-ket-qua](https://xettuyen.hcmue.edu.vn/tra-cuu-ket-qua)
2. Nhấn phím `F12` (hoặc click chuột phải chọn **Kiểm tra / Inspect**) để mở Developer Tools.
3. Chuyển sang tab **Console**.
4. Sao chép toàn bộ nội dung file `crawl.js` và dán vào cửa sổ Console.
5. Nhấn `Enter` và chờ chương trình tự động chạy.
